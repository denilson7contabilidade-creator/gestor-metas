# Gestor de Metas

App de metas e afazeres para celular, instalável pelo Chrome (Android). Faz parte da mesma família do Gestor de Finanças.

- **Hoje:** afazeres do dia, com horário, repetição (todo dia ou segunda a sexta) e aviso.
- **Metas:** metas por ano, medidas como lista (ex.: 12 livros), dinheiro, número (ex.: km) ou sim/não.
- **Compras:** lista do que comprar, com quantidade e preço estimado.
- **Lembretes:** notificação no celular no horário do afazer e resumo do dia; atalho para pôr o afazer na agenda do celular.
- Os dados ficam **só no aparelho**. Backup em arquivo para trocar de celular.
- Funciona sem internet depois de instalado.

Este repositório guarda apenas o código do app. Nenhum dado é enviado para cá.
